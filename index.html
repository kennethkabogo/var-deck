The Problem

Agents act.
Nobody can prove what they did.

Every AI agent action today is backed by a software log — and logs can be silently altered by the operator who controls the host.

What this does not cover. VAR attests what the runtime reports. An agent that subverts the tool-execution layer produces a faithfully signed but false record — the boundary is the executor, not the chain. METR found 96 of ~1,300 transcripts carrying spoofed tool calls in the Hugging Face incident; that failure mode is real and orthogonal to this one.

Competition

Everyone proves something.
Nobody leaves a record to check.

Seven categories get compared to VAR. Each proves something real. None of them leaves anything to check what the agent actually did.

CategoryTheir gapVAR’s edge
Agentic payment protocolsACP · AP2 · agentic network tokens Signed mandates attest permission: what the user authorised, what the merchant offered, how settlement happens. Not what the agent did in between. Attests execution, not authorisation. Composes with a mandate rather than replacing it — a Cart Mandate can reference the terminal digest of the run that produced it.
Agent credential infrastructureTurnkey Non-custodial credentials, policy-gated by a permission and approval engine. Governs what an agent can act with. Says nothing about what it did once authorised. Composes above it, not against it: Turnkey gates the credential, VAR attests the execution it was used for.
Attested agent infrastructurePopcorn / Reclaim · Solari Proves the environment was the approved image at proof time. Their own docs: does not prove “that an agent will behave correctly.” Hash-chained record of the actions inside that environment, ordered and replayable by someone who wasn’t there.
ObservabilityLangsmith · Arize · Helicone Operator controls every log. Records can be altered after the fact. Designed for an adversarial operator. Hardware-enforced, not log-based.
Confidential computeAnjuna · Gramine · Enarx Proves the right binary runs. Says nothing about what the agent decided. Seals the room and records what happened inside it.
ZK-based verification Proof generation latency. No hardware root of trust. No settlement primitive. Hardware is faster. Root of trust is silicon, not math. ZK is complementary long-term.
Crypto trust layerst54 Labs · AEON · Eigen Cloud Trust model is economic incentives — adversarial operator is discouraged, not prevented. PCR-gated signing makes post-hoc alteration impossible. Not costly. Impossible.
